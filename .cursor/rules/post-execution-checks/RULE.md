# エージェント実行後の品質チェック

エージェントがコードの追加・修正を行った場合**のみ**、以下のコマンドを順番に実行して、コードの品質を確認してください。

## 実行条件

**重要**: このルールは、エージェントが以下のいずれかの操作を行った場合**のみ**適用されます：

- 新しいファイルを作成した場合
- 既存のファイルを編集・修正した場合
- コードの追加・削除・変更を行った場合

コード変更がない場合（例：質問への回答のみ、ドキュメントの参照のみなど）は、これらのコマンドを実行する必要はありません。

## 必須実行コマンド

コードの追加・修正を行った場合は、以下の3つのコマンドを必ず順番に実行してください：

```bash
pnpm format
pnpm lint
pnpm test
```

## 実行順序

1. **`pnpm format`** - Prettierを使用してコードをフォーマット
2. **`pnpm lint`** - ESLintを使用してコードのリントチェックと自動修正
3. **`pnpm test`** - Jestを使用してユニットテストを実行

## 注意事項

- コード変更を行った場合のみ、これらのコマンドを実行してください
- テストが失敗した場合は、エラーを修正してから再度テストを実行してください
- リントエラーが残っている場合は、可能な限り修正してください
